# LNCR 12S 90A

A **3lb (Beetleweight) Combat-Robotics-Optimized Clone of the TBS Lucid 12S 90A AM32 ESC**, designed for **JLCPCB 4-layer 2 oz Single-Sided SMT** fabrication to replace the **NeutronRC 70A** ESC.

- **Voltage Rating:** 3S–12S LiPo/LiHV (up to 50.4 V nominal / 52.2 V LiHV, 100 V power stage)
- **Current Rating:** 90 A continuous / 120 A burst (`6× HYG016N10NS1TA` TOLL-8L + `0.25 mΩ` shunt)
- **AM32 Firmware Target:** `TBS_12S_F421` (`AT32F421G8U7`, `HARDWARE_GROUP_AT_C` + `HARDWARE_GROUP_AT_045`)
